# 넷스위치 (NetSwitch)

느린 Wi-Fi / 느린 모바일 데이터를 감지해서 **자동으로 더 빠른 쪽으로 전환**하는 안드로이드 앱입니다.
일반 앱은 Android 10부터 Wi-Fi를 켜고 끌 수 없어서, [Shizuku](https://shizuku.rikka.app/)로 ADB 권한을 받아 동작합니다.

## 동작 방식
- 설정한 주기마다 현재 연결의 응답시간과 속도를 측정합니다.
- **Wi-Fi가 연속으로 느릴 때**
  1. "전환 후보 Wi-Fi" 중 신호가 잡히는 곳이 있으면 그 Wi-Fi로 연결합니다.
  2. 없으면 모바일 데이터를 잠깐 측정해서, 설정한 배수 이상 빠르면 Wi-Fi를 끄고 모바일 데이터로 넘어갑니다.
- **Wi-Fi를 꺼둔 동안**: 몇 분마다 Wi-Fi를 다시 켜서 확인합니다. 계속 느리면 확인 간격을 최대 8배까지 늘립니다. 모바일 데이터도 느려지면 즉시 Wi-Fi를 다시 켭니다.
- **모바일 데이터가 느린데 Wi-Fi는 켜져만 있을 때**: 후보 Wi-Fi가 보이면 연결합니다.
- 감시를 중지하면 앱이 꺼둔 Wi-Fi를 다시 켭니다. 사용자가 직접 끈 Wi-Fi는 건드리지 않습니다.

## 설치
1. GitHub의 **Actions → Build APK → 최신 실행 → Artifacts**에서 `NetSwitch-apk`를 받아 설치합니다.
2. Play 스토어에서 **Shizuku**를 설치합니다.
3. 휴대폰 설정 > 휴대전화 정보 > 소프트웨어 정보 > **빌드번호 7번 탭**해서 개발자 옵션을 켭니다.
4. 개발자 옵션 > **무선 디버깅**을 켜고, Shizuku 앱에서 "무선 디버깅으로 시작" → 페어링합니다.
5. 넷스위치에서 **권한 요청 → 연결 테스트 → 감시 시작**을 누릅니다.
6. **배터리 최적화 제외**도 눌러주세요. 삼성은 백그라운드 앱을 자주 종료합니다.

> 휴대폰을 재부팅하면 Shizuku를 다시 시작해야 합니다 (Shizuku 앱에서 한 번 탭).

## 참고
- 모바일 데이터는 전환 여부를 판단할 때만 속도를 측정합니다 (회당 약 0.3MB, 최소 2분 간격).
- 후보 Wi-Fi 비밀번호는 이 앱의 내부 저장소에만 저장됩니다.
- WPA2/WPA3 개인용과 개방형 Wi-Fi만 지원합니다 (회사용 EAP 방식은 지원하지 않음).
